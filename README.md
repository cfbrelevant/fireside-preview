# Fireside — list once, share everywhere

A lightweight prototype for a Utah rental listing hub with an interactive owner listing studio.

## Preview

- `index.html`: home, sharing infographic, fictional sample rental directory, explainer and community pitch
- `kandi.html`: Kandi’s Listing Studio, with local browser draft saving, photo preview, three generated post styles, copy controls, checklist, and text download

## What works

- Create and edit draft rental posts in the current browser (localStorage).
- Select up to 8 photo files for visual preview (not uploaded, and not retained after a reload).
- Copy ready-to-paste KSL Classifieds, Facebook Marketplace, and group posts.
- Track which platforms you posted to in the local browser.
- Browse fictional sample properties and demo a local listing.

## What does NOT work yet

- No account authentication or access protection for Kandi’s page. Do not put sensitive information in the demo.
- No server photo uploads, database, real rental publication, or syncing across devices.
- No automatic third-party posting or affiliation with KSL, Facebook, or any LDS housing organization. Post text manually to each platform, subject to their rules.
- No payment processing or booking.

The subdomain `fireside.utahsands.com` requires DNS setup at the user's domain registrar or DNS provider.
